# interior

Про то, как мы делали дизайн без дизайнера.

Квартира в Нидерландах: Г-образная планировка, объединённая кухня-гостиная с балконом, две спальни, гардеробная, прихожая и длинный узкий коридор. Угол квартиры смотрит примерно на 120° от севера: три окна гостиной — на северо-восток, балконная стена, спальня и кабинет — на юго-восток, то есть с прямым утренним солнцем. Потолки около 2,58–2,59 м по факту. Пол — медово-золотой дуб на масле, он и задаёт всю палитру: тепло уже есть, добавлять жёлтого нельзя.

## Структура папок

- [`colors/`](colors/) — цвет: краски, палитра, обои.
- [`planning/`](planning/) — планировка, замеры, общие заметки по проекту.
- [`rooms/`](rooms/) — решения по конкретным комнатам: хранение, мебель, расстановка.
- [`textiles/`](textiles/) — ковры, шторы, ткани.
- [`materials/`](materials/) — фотографии неизменяемой отделки и замеры их цвета: пол, столешница.
- [`budget/`](budget/) — сметы, цены, контакты подрядчиков.

Папки заводим по мере необходимости — если что-то не влезает в существующую категорию, лучше завести новую, чем складывать не туда.

## Принципы, которые уже закрепились

- **Цвета сравниваем по числам, а не на глаз.** Перевод в CIE Lab и сравнение по светлоте, насыщенности и углу оттенка. «Слишком бледный» почти всегда означает низкую насыщенность, а не высокую светлоту.
- **Названия цветов из переписки проверяем по каталогу.** Несколько названий оказались несуществующими и были исправлены по номеру.
- **Ничего не заказываем по экрану.** Финальный выбор — только по физическим выкраскам и образцам ткани, при дневном свете и рядом с дубовым полом.
